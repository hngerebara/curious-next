# New user onboarding

## Flow

Capture an adult learner's goal, teaching language, explanation preference, and available time. Clarify supported outcomes without inventing a curriculum. Generate one personalised proposal within Practical AI or Cybersecurity Essentials from the versioned objective catalogue. Include a fit explanation and prerequisite closure. Vague or mixed goals receive one clarification. Unsupported goals receive supported alternatives. Let the learner accept or revise the proposal before optional placement. See the [generation contract](../design-docs/course-generation.md).

Offer a short optional diagnostic or Start from the beginning. Diagnostic placement is provisional and awards no mastery. Skipping starts module one. Recommend a first action with its reason and estimated duration. Preferences remain editable.

## Accessibility and validation

Keyboard and screen-reader access apply throughout. Language availability must be honest, with no silent fallback. Do not request a disability diagnosis. Validate diagnostic skip, later placement, preference changes and preserved progress.

Detailed rules: [pilot design](pilot-design.md). [Product contract](../../Prompt.md).
