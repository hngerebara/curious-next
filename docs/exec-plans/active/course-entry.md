Run application/governance checks, real-session ownership/concurrency journeys, mobile/keyboard/error checks and accessibility semantics. Review, fix, publish ticket-linked PR, verify latest-head CI and leave unmerged. M2 completion additionally requires configured Neon/Resend journey and actual screen-reader walkthrough. No secrets, delivery, hosted migration or paid resource provisioning is implied by local tests. M1 content review and M6 participant/language release remain separate gates.
